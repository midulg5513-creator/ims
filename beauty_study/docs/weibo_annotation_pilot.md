# 微博广告内容标注试验集

来源：Hugging Face 公开数据集 [dirtycomputer/weibo_senti_100k](https://huggingface.co/datasets/dirtycomputer/weibo_senti_100k)。原数据是微博情感数据，以下标签为本项目重新人工标注的试验字段，不是原数据集自带标签。

注意：该数据集不保证保留账号身份、发布时间和互动数，因此本文件只用于测试标签体系，不用于估计广告效果。

## 标签定义

- 商业意图：`0` 非商业；`1` 软性种草；`2` 明确促销/转化；`3` 品牌公关/形象；`4` 无法判断。
- 营销策略：可多选，如 `抽奖`、`新品`、`明星/代言`、`功效`、`优惠`、`直播`、`话题`、`购买引导`、`用户体验`。
- 表达方式：`信息型`、`情绪型`、`互动型`、`促销型`、`场景/故事型`。

## 建议复核的边界案例

1. 第2、8、10、11、13、15条：需要先确定账号类型。若研究“品牌官方广告”，应排除或单独建模；若研究“微博整体种草”，可以保留。
2. 第3、5、9、12、14条：商业意图明确，但有些内容可能是回复或转发链，正式采集时应保留 `is_original` 和 `parent_post_id`。
3. 第1、15条：出现“补水神器”“第二天痘痘就瘪掉”等强功效表述，建议额外标记 `exaggerated_claim = 1`，不要把它和普通功效说明混在一起。

## 这批试标集的用途

正式采集前，先让第二位标注者独立复核这15条。重点计算：

- 商业意图的 Cohen's Kappa；
- 多标签策略的逐标签 F1 或 Jaccard；
- 对第2、8、10、11、13、15条的账号类型判断一致性。

如果商业意图的 Kappa 低于0.60，应先修订定义，再扩大到正式样本。
